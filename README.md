# Révisions — version tablette

Appli familiale de révisions (petite section → CM2) : jeux à la voix, XP, pièces, boutique de récompenses,
récré avec mini-jeux, espace parents protégé par un code. Tout tourne et tout est gardé dans la tablette :
pas de compte, pas de serveur, pas de publicité, rien n'est envoyé nulle part.

**Version 0.7.7** — à ouvrir sur la tablette : https://tchangy-studio.github.io/revisions-tablette/ puis « Ajouter à l'écran d'accueil ».
Elle marche ensuite sans Internet et se met à jour toute seule quand Internet est là.

Ce dépôt ne contient que l'appli assemblée, publiée automatiquement à chaque version de Révisions.
